# Decorators

Домашнее задание к лекции «Decorators».

## Содержание

- `task_1.py` — декоратор `logger`, который записывает вызовы функций в `main.log`.
- `task_2.py` — параметризованный декоратор `logger(path)` с выбором файла журнала.
- `task_3.py` — применение параметризованного декоратора к итератору из домашней работы «Iterators. Generators. Yield».
- `flat_iterator.py` — класс `FlatIterator` из предыдущего задания.

В журнал записываются дата и время, имя функции, позиционные и именованные аргументы, возвращаемое значение.

## Запуск

```bash
python task_1.py
python task_2.py
python task_3.py
```

Для каждого задания предусмотрена проверка через `assert`. При успешном выполнении ошибок не будет. Файлы журналов создаются в текущей рабочей папке и не добавляются в репозиторий.

Дополнительные библиотеки не требуются.
